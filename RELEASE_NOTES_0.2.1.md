# MW Arcade Drift 0.2.1

0.2.0からの変更点

- スペシャルモードでドリフトカメラが作動しない不具合を修正しました。
- 空転する駆動輪の回転が速く見えるようにし、空転時のタイヤ煙の演出を強化しました。
- スペシャルの操舵応答を変える「ドリフト演算強化」を追加しました。初期状態はONです。4WDには不向きで、Editor 0.2.1からプロファイル別にOFFにできます。

更新時はゲームを終了し、同梱の2つのASIを更新してください。既存のINIとプロファイルはそのまま使用できます。MW Arcade Drift AIはコアに同梱しています。エディターは別ダウンロードです。

---

Changes since 0.2.0

- Fixed the drift camera failing to activate in Special mode.
- Made spinning drive wheels rotate faster on screen and strengthened tyre smoke during wheelspin.
- Added Enhanced drift calculation, which changes steering response in Special mode. It is on by default and is unsuitable for 4WD. You can turn it off per profile in Editor 0.2.1.

Close the game and replace both included ASIs. Keep your existing INIs and profiles. MW Arcade Drift AI is bundled with the core. The editor is a separate download.
