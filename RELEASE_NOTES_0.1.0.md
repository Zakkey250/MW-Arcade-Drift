# MW Arcade Drift 0.1.0

First public release of the player-car arcade drift mod for NFS Most Wanted (2005).

- Brake-initiated drifts, handbrake angle addition and smoother counter-steer recovery.
- Drift camera and compact three-state slip indicator.
- Visual drivetrain behavior: RWD rear spin, AWD/4WD all-wheel spin, FWD counter-steer without artificial spin.
- Default and per-car JSON drift/camera profiles, generated on first vehicle entry and reloaded with Ctrl+D OFF→ON.
- Optional bilingual slider editor in a separate download; Core contains no EXE.

**Tuning:** Use the game's Performance Tuning (Handling) first. Use the optional editor if the in-game setting does not give you the desired balance.

Install Core by extracting `scripts/` into the game directory with the game closed. Editor can be added later. Preserve existing settings when updating. The two supported executable SHA-256 values and detailed instructions are in the Core ZIP and README. AI racers and police are unchanged.

The preceding alpha.4 version completed a user-observed drive without conspicuous issues. In its log, 288 drifts reached completion; no MOD fault, configuration error or HUD failure appeared. FWD visual behavior and the gray disabled icon remain outside that observed run. 0.1.0 retains its gameplay implementation with a new version label and public default telemetry disabled.
